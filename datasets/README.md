# Coleções de partidas

Coloque aqui arquivos `.pgn` de partidas históricas. Use PGN em UTF-8, xadrez padrão, até 20 MB e 1000 partidas por arquivo. Comentários e variantes anotadas não são reproduzidos: o visualizador mostra a linha principal. Posições iniciais FEN são suportadas.

`exemplo.pgn` contém apenas sequências didáticas locais para demonstrar o visualizador; não é um dataset de jogadores famosos e não deve ser apresentado como tal.

`historicas.pgn`: transcrição própria dos lances factuais da Partida da Ópera (Paul Morphy contra Duke Karl / Count Isouard, Paris, 1858), conferidos em https://en.wikipedia.org/wiki/Opera_Game e com contexto em https://www.chess.com/terms/opera-game-chess em 06/10/2026. Registro histórico de 17 lances (33 meios-lances). Não foram copiados comentários, análises, imagens ou uma coleção proprietária. O PGN usa somente o registro factual e metadados mínimos; a data exata é deixada desconhecida. Esta é uma amostra histórica, não uma base extensa de treinamento.

Para cada coleção adicionada, registre aqui: nome do arquivo, fonte/URL, data de obtenção, licença/permissão de uso e filtros aplicados. Não copie coleções sem verificar as condições da fonte.

Nesta etapa, os dados são usados para reprodução e estudo. Não treinam a rede do Stockfish nem alteram a seleção dos lances durante partidas do campeonato.
